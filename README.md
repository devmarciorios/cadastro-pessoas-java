# Sistema de Cadastro de Pessoas (JAVA)

Projeto desenvolvido para por em prática conceitos de programação com Orientação a Objetos e Tratamento de Exceções em JAVA.

## Funcionalidades:
- Cadastro de clientes e funcionários
- Validação de idade mínima de 18 anos
- Exibição das informações dos cadastrados
- Interface pagável

## Tecnologias utilizadas:
- Desenvolvido em JAVA
- Intellij IDEA
- GIT/Github

## Como executar este projeto:
1. Clone este repositório: 
git clone https://github.com/devmarciorios/cadastro-pessoas-java.git
2. Compile e exeucte a classe 'main.java'
